Anatomía de un script
Un script de Bash es un archivo de texto con órdenes que Linux ejecuta de arriba hacia abajo. Estas son sus partes.

    

    

      
mi_script.sh

        

      
    
    
    
  
    

  
    
    
    
      
    
      
    Cómo ejecutar un script
    Tres pasos y tu script está funcionando.
    
    
    
    
    
      
    1
    Crea el archivo
    Escribe o pega el script en un editor de texto.
    nano menu.sh
    
      
    2
    Dale permiso
    Permite que el archivo se pueda ejecutar.
    chmod +x menu.sh
    
      
    3
    Ejecútalo
    Lánzalo desde la carpeta donde está.
    ./menu.sh
